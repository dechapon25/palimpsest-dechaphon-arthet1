## Layout Structure

Single-page, vertical layout. No tabs. Sections render top-to-bottom in this exact order:

| Order | Section | Components |
|-------|---------|-----------|
| 1 | Upload | `gr.File` (single image) + `gr.Button` ("Transcribe Manuscript") |
| 2 | Transcription | `gr.Radio` (Raw / Cleaned toggle) + `gr.Textbox` (read-only, shows selected text) |
| 3 | Historical Notes | `gr.Markdown` (entity table rendered as Markdown) |
| 4 | Confidence Map | `gr.HTML` (highlighted word spans) |

## Spacing Scale

Declared values (multiples of 4). Gradio manages internal component padding; these values apply to `gr.Blocks` layout parameters.

| Token | Value | Gradio Usage |
|-------|-------|-------------|
| xs | 4px | Inline span horizontal padding for confidence highlight `<span>` elements |
| sm | 8px | Gap between label and component within a section |
| md | 16px | Default `gr.Group` padding; `gr.Row` gap |
| lg | 24px | Gap between major sections in `gr.Column` |
| xl | 32px | Top/bottom margin on the app container |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Confidence highlight `<span>` elements use `padding: 0 2px` (not on the 4px grid — this is inline text formatting, not layout spacing).

## Typography

Gradio inherits Inter / system-ui from the Soft theme. Declare these roles explicitly for inline HTML in the Confidence Map section.

| Role | Size | Weight | Line Height | Used In |
|------|------|--------|-------------|---------|
| Body | 16px | 400 | 1.5 | `gr.Textbox`, `gr.Markdown` body text |
| Label | 14px | 600 | 1.4 | Gradio component labels, Radio choices, table headers |
| Heading | 20px | 600 | 1.3 | `gr.Markdown` `##` section headings |
| Display | 28px | 700 | 1.2 | App title in `gr.Blocks` header (via `title=` param) |

Confidence Map inline HTML inherits body typography (16px / 400 / 1.5) from surrounding Gradio output — do not override font-family, size, or weight on `<span>` elements.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Page background, `gr.Textbox` surfaces, `gr.HTML` background |
| Secondary (30%) | `#f3f4f6` | Section panel backgrounds, `gr.Group` containers, table rows |
| Accent (10%) | `rgba(255, 165, 0, {opacity})` | Confidence highlight spans ONLY — not for buttons, links, or any other element |
| Destructive | Gradio `gr.Error` default red | `gr.Error()` pop-up banner — not a custom color, uses Gradio system |

Accent reserved for: uncertainty highlight `<span>` elements in the Confidence Map section exclusively. The opacity encodes confidence level — formula: `opacity = 1 - score`. Score 0.0 renders as fully opaque orange (`rgba(255,165,0,1.0)`); score 0.69 renders as pale yellow (`rgba(255,165,0,0.31)`). Confident words (score >= 0.7) are plain text with no background color.

> Source: CONTEXT.md D-14, D-15.

### Confidence Highlight Formula

```python
# For each word in confidence_map where score < 0.7:
opacity = round(1 - score, 2)
style = f"background-color: rgba(255, 165, 0, {opacity})"
title = f"score: {score} | reason: {reason}"
html = f'<span style="{style}" title="{title}">{word}</span>'

# For confident words (score >= 0.7):
html = word  # plain text, no span
```

## Interaction Contract

### Click Handler Flow

```
User clicks "Transcribe Manuscript"
  → Button sets interactive=False, value="Processing…"
  → Security intake: validate file type (JPG/PNG only) and size (≤ 20 MB)
      → If invalid: raise gr.Error("File must be JPG or PNG under 20 MB.")
  → asyncio.run(run_pipeline(clean_bytes, mime_type, filename))
  → If result["status"] == "error": raise gr.Error(error_message)
  → Populate outputs:
      - Transcription Textbox: result["cleaned_transcription"]["cleaned_text"]
      - Historical Notes Markdown: render_context_table(result["context_notes"])
      - Confidence Map HTML: render_confidence_html(result["confidence_map"])
  → Button resets: interactive=True, value="Transcribe Manuscript"
```

### Raw/Cleaned Toggle

```
User selects "Raw" in gr.Radio
  → Transcription Textbox updates to result["raw_transcription"]["raw_text"]
User selects "Cleaned" in gr.Radio
  → Transcription Textbox updates to result["cleaned_transcription"]["cleaned_text"]
Confidence Map HTML is NOT affected by this toggle — always shows cleaned + highlights.
```

> Source: CONTEXT.md D-08, D-13, D-17.

### Tooltip Interaction

Uncertain words in the Confidence Map render with a native browser `title=` attribute. No JavaScript required. On hover, browser displays: `score: {score} | reason: {reason}`.

> Source: CONTEXT.md D-16.

## Session State Keys (Read-Only Reference)

The UI reads these keys from the `run_pipeline()` return dict:

| Key | Type | UI Consumer |
|-----|------|-------------|
| `raw_transcription` | JSON string `{"raw_text": str}` | Transcription Textbox (Raw mode) |
| `cleaned_transcription` | JSON string `{"cleaned_text": str, "changes": list}` | Transcription Textbox (Cleaned mode) |
| `context_notes` | JSON string — array of entity dicts | Historical Notes Markdown |
| `confidence_map` | JSON string — array of `{"word", "score", "reason"}` dicts | Confidence Map HTML |
| `status` | `"ok"` or `"error"` | Error gate before populating outputs |
| `errors` | list of strings | Passed to `gr.Error()` |

> Source: CONTEXT.md D-03, D-06, orchestrator.py D-11 schema.

## Helper Function Contracts

### `render_confidence_html(word_scores: list[dict]) -> str`

- Input: list of dicts with keys `word`, `score`, `reason`
- Output: HTML string — words joined with spaces, uncertain words wrapped in styled `<span>`
- Wrap output in `<div style="font-size:16px;line-height:1.5;font-family:inherit">...</div>`
- Threshold: score < 0.7 gets a highlight span; score >= 0.7 is plain text
- Join words with `" "` (single space) to preserve word boundaries

### `render_context_table(context_notes: list[dict]) -> str`

- Input: list of entity dicts from context agent (keys: entity, type, description, date, source/wikidata_id)
- Output: Markdown table string with header row: `| Entity | Type | Description | Date | Source |`
- Empty input: return `"No historical entities found in this document."`
- Truncate description to 120 characters per row to keep the table readable
