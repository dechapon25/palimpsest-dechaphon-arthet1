## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline char padding inside confidence spans |
| sm | 8px | Toggle group inner padding, status label gap |
| md | 16px | Card inner padding (horizontal), element spacing |
| lg | 24px | Card inner padding (vertical), section gap between cards |
| xl | 32px | Upload zone vertical padding |
| 2xl | 48px | Page top/bottom margin |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Card inner padding: 20px (horizontal) — Bento aesthetic requires slightly wider than md; this is a one-off composite value, not a new token
- Bento grid gap between cards: 12px — between the standard sm (8) and md (16) values; acceptable for grid-gap
- Confidence span inline padding: `0 2px` — carries over from existing `render_confidence_html()` (preserve verbatim per D-07 scope constraint)

  `render_confidence_html()` inline style — preserve verbatim.

- The display title uses `## ` prefix (H2) in gr.Markdown, consistent with existing
  `gr.Markdown("## Palimpsest")` — no change needed.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0F172A` | Page background, outer wrapper, upload screen bg |
| Secondary (30%) | `rgba(30, 41, 59, 0.6)` | Card surface (glassmorphism frosted-glass bg) |
| Accent (10%) | `#C9A84C` | See reserved-for list below |
| Destructive | `#DC2626` | System error state only (gr.Error pop-up — Gradio native styling) |

**Accent `#C9A84C` reserved for:**
1. "Transcribir" primary CTA button background
2. Upload zone dashed border
3. "Nueva transcripción" button border and text color
4. Status progress indicator dot/spinner
5. Card section title left border accent (`border-left: 3px solid #C9A84C`)

**Not** used for: body text, table content, confidence highlights (those use `rgba(255, 165, 0, {opacity})` — existing pattern preserved per D-07).

**Glassmorphism card surface tokens (derived from secondary):**
- Background: `rgba(30, 41, 59, 0.6)`
- Backdrop filter: `blur(12px)`
- Border: `1px solid rgba(201, 168, 76, 0.15)` (amber at 15% opacity)
- Box shadow: `0 4px 24px rgba(0, 0, 0, 0.4)`
- Border radius: `12px`

**Confidence highlight color (preserve existing):**
- Uncertain word background: `rgba(255, 165, 0, {opacity})` where opacity = `1 - score`
- This value comes from `render_confidence_html()` and must NOT be changed (D-07 scope).

## Bento Grid Layout

Implemented as CSS Grid on the results section wrapper. Two named-area configurations:

**Grid area map (results section, post-processing):**

```
"transcription  confidence"
"notes          notes      "
```

- `transcription`: left column, rows 1 — 60% width. Houses transcription text + Raw/Limpiada toggle.
- `confidence`: right column, row 1 — 40% width. Houses confidence map HTML.
- `notes`: full width, row 2. Houses historical notes Markdown table.

**Grid CSS (inject via `gr.Blocks(css=...)`):**

```css
.bento-results {
  display: grid;
  grid-template-columns: 3fr 2fr;
  grid-template-rows: auto auto;
  grid-template-areas:
    "transcription confidence"
    "notes         notes";
  gap: 12px;
  padding: 0;
}
.bento-transcription { grid-area: transcription; }
.bento-confidence    { grid-area: confidence; }
.bento-notes         { grid-area: notes; }
```

**Gradio CSS targeting:** Gradio Blocks accepts a global `css=` string. Target component
wrappers with `.gradio-container`, `.block`, or custom `elem_classes` on each gr.Column.
Use `elem_classes=["bento-transcription"]` etc. on each gr.Column wrapper.

## Interaction States

| State | Visible Elements | Hidden Elements |
|-------|-----------------|-----------------|
| **Initial (upload)** | upload zone, "Transcribir" btn, status line (empty) | all result cards, "Nueva transcripción" btn |
| **Processing** | upload zone, "Transcribir" btn (disabled), status line ("Procesando…") | all result cards, "Nueva transcripción" btn |
| **Results shown** | upload zone, status line ("Completado"), all 3 result cards, "Nueva transcripción" btn | none |
| **Reset** | returns to Initial state | same as Initial |

**Reveal order (D-01 — LOCKED):**
1. Transcription card (`visible=True`) — shown when `cleaned_text` is non-empty
2. Confidence card (`visible=True`) — shown after transcription card
3. Historical notes card (`visible=True`) — shown last
4. "Nueva transcripción" button (`visible=True`) — appears after all 3 cards revealed

**Implementation pattern:**
Each result section wrapped in `gr.Column(visible=False, elem_classes=[...])`.
`transcribe_manuscript()` return tuple extended to include `gr.update(visible=True)`
values for each wrapper. Reset handler returns `gr.update(visible=False)` for all wrappers.

**CSS constant structure (in `app.py`):**

```python

/* === Palimpsest Wizard — Bento Grid + Glassmorphism === */

/* 1. Page background */
.gradio-container {
    background-color: #0F172A !important;
    min-height: 100vh;
}

/* 2. Glassmorphism card base */
.glass-card {

    border-radius: 12px;
    box-shadow: 0 4px 24px rgba(0, 0, 0, 0.4);
    padding: 20px 20px 24px 20px;
}

/* 3. Card title accent bar */
.glass-card h3 {
    border-left: 3px solid #C9A84C;
    padding-left: 8px;
    margin-bottom: 16px;

}

/* 4. Bento grid for results section */
.bento-results {
    display: grid;
    grid-template-columns: 3fr 2fr;
    grid-template-rows: auto auto;
    grid-template-areas:
        "transcription confidence"

    border-radius: 8px !important;
}

/* 7. Reset button */
.btn-reset {
    border: 1px solid #C9A84C !important;
    color: #C9A84C !important;
    background: transparent !important;
    border-radius: 8px !important;
}

/* 8. Status line */
.status-line {
    font-size: 13px;
    color: #C9A84C;
    font-family: system-ui, -apple-system, sans-serif;
    min-height: 20px;
}

/* 9. App title */
```

**Note:** `!important` is required on specific rules because Gradio 6.x injects component-level
inline styles with high specificity. Use sparingly — only where Gradio overrides are confirmed
during implementation.

## Accessibility Constraints

- All interactive elements retain visible focus ring (Gradio default — do not remove with CSS)
- Upload zone `gr.File` keeps its native label attribute (ARIA accessible)
- `gr.Button` text must be descriptive: "Transcribir" and "Nueva transcripción" are sufficient
- Confidence highlight tooltip uses `title=` attribute (existing pattern — preserve verbatim)
- Color contrast: white text `#F1F5F9` on `#0F172A` background = 15.7:1 (WCAG AAA)
- Accent `#C9A84C` on `#0F172A` = 6.2:1 (WCAG AA — passes for normal text)
- Glassmorphism card text: `#CBD5E1` on `rgba(30, 41, 59, 0.6)` over `#0F172A` ≈ `#252E3F` solid = 9.4:1 (WCAG AAA)
