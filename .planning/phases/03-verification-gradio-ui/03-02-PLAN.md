    - If word_scores is falsy or empty, return the string "(confidence map will appear after processing)" wrapped in a div with style="font-size:16px;line-height:1.5;font-family:inherit".

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User browser → gr.File upload | Untrusted file bytes enter; controlled by gr.File(file_types=) client-side and validate_and_clean() server-side |
| confidence_map JSON (LLM output) → render_confidence_html() | LLM-generated word strings inserted into HTML — XSS risk if not escaped |
| run_pipeline() errors list → gr.Error() | Pipeline error strings from Gemini or ADK displayed in browser banner |
| .env → app.py startup | GOOGLE_API_KEY loaded from .env; must not be logged or displayed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Tampering / XSS | render_confidence_html() — word and reason fields from LLM output inserted into gr.HTML | medium | mitigate | html.escape(word) and html.escape(reason) on every iteration before string interpolation into span elements. Both fields escaped, not just word. |
| T-03-04 | Information Disclosure | GOOGLE_API_KEY exposure via Gradio UI or logs | high | mitigate | load_dotenv() loads from .env (not in repo); no log statements referencing os.environ["GOOGLE_API_KEY"]; key never displayed in Gradio outputs; gr.Error messages contain only user-visible error text, not env values. |
| T-03-05 | Denial of Service | Very large manuscripts: confidence_map array length → large HTML string in gr.HTML | low | accept | Demo context; no concurrent public users during Kaggle judging; Gradio renders HTML client-side. Flash context window is the binding limit. No mitigation needed for demo phase. |
| T-03-06 | Information Disclosure | Gradio temp files: gr.File stores upload in system temp dir | low | accept | Gradio 5.x manages temp file lifecycle per session; no persistence to project directory; EXIF data already stripped by validate_and_clean() before pipeline. |
| T-03-SC | Tampering | gradio==5.50.0 package install | low | accept | Package legitimacy audit in RESEARCH.md confirms: 6+ year old package, millions downloads/month, official Hugging Face-maintained library. False-positive SUS verdict from legitimacy seam. |
</threat_model>
