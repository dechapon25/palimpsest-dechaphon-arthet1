**Part B — Inline code comments per D-21 (DOC-02):**

Add comments using the pattern: one or two `# Why:` sentences immediately above or following the relevant code line. Apply exactly the 6 decisions listed in D-21:

1. **thinkingBudget=128** in `src/palimpsest/agents/transcription.py` — comment: lower thinking budget is counterintuitive but correct for transcription tasks; higher budgets cause the model to over-analyze cursive stroke ambiguities rather than simply reading the text

2. **filetype.guess() before Pillow.open()** in `src/palimpsest/security/intake.py` — comment: magic-byte validation must precede image parsing; Pillow trusts the file extension, but filetype reads the actual byte signature; this catches renamed non-image files (e.g., a DOCX renamed to .jpg) before any image decoding occurs

3. **maxOutputTokens=65536** in `src/palimpsest/agents/transcription.py` — comment: the default 8192 token limit silently truncates multi-page manuscripts mid-transcription without any error; 65536 is explicitly required for complete output (TRS-01)

4. **stdio transport for MCP** in `src/palimpsest/agents/context.py` — comment: stdio transport requires a parent/child process relationship (McpToolset spawns the server as a subprocess via sys.executable); stdio cannot cross container or network boundaries — if multi-container deploy is ever needed, switch to HTTP transport and run mcp/server.py separately on a fixed port

5. **temperature=0.1** in `src/palimpsest/agents/transcription.py` — comment: low temperature reduces variance on proper nouns and place names, which must be transcribed exactly; higher temperature introduces hallucinated name variants

6. **SEC-04 system prompt pattern** — add a brief comment in the file where the system prompt labels manuscript text as DATA (already in transcription.py and context.py docstrings per PATTERNS.md; add in cleaning.py and verification.py module docstrings if those agents have system prompts with the DATA labeling pattern)
