## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Gradio CSS class targeting | Gradio 6.x uses Svelte hashed classes (e.g. `.svelte-1uj8rng`) not semantic names. Targeting `.btn-primary`, `.progress-bar` etc. silently fails. | blocking | Override CSS variables (`--loader-color`, `--block-background-fill`) on `.gradio-container`, not element classes. Use `elem_classes` for own components. |
| outputs_full tuple length mismatch | `transcribe_manuscript()` and `reset_manuscript()` both must return exact same N-element tuple as `outputs_full`. Adding a component without updating both handlers silently breaks the UI. | blocking | Plan 06-02 adds processing_section → tuple goes 10→11. Update BOTH functions. |
| Google Fonts blocked | Google Fonts via `@import url(...)` in CUSTOM_CSS may not load in Gradio's CSP sandbox depending on deploy env. | advisory | Test locally first. Fallback: system-ui for Hanken Grotesk, Georgia for Spectral. |
