Implement four @mcp.tool() decorated functions:

1. lookup_entity(name: str) -> dict (MCP-01, MCP-05):
   - Step 1: Call Wikidata wbsearchentities API with action=wbsearchentities, search=name, language=es, format=json, limit=5, type=item. Include HEADERS and timeout=10.
   - Step 2: If no results, return {"found": False, "entity": name, "error": "No Wikidata match found"}
   - Step 3: Take top result QID. Execute SPARQL query for itemLabel, itemDescription, birthDate (P569), deathDate (P570), birthPlaceLabel (P19), occupationLabel (P106) using SERVICE wikibase:label with language "es,en". Timeout=15.
   - Step 4: Return {"found": True, "entity": name, "wikidata_id": qid, "description": ..., "dates": ..., "source_url": "https://www.wikidata.org/wiki/{qid}"}
   - Wrap all network calls in try/except for requests.RequestException, returning {"found": False, "entity": name, "error": str(e)}

2. normalize_date(text: str) -> dict (MCP-02):
   - Use Python re module to parse common archaic Spanish date patterns:
     - "el NN de MONTH del anno YYYY" or "el NN de MONTH de YYYY"
     - Numeric patterns like "25 de junio de 1782"
   - Define a SPANISH_MONTHS dict mapping month names (enero through diciembre) to numbers
   - If regex matches, construct ISO 8601 date string (YYYY-MM-DD)
   - If no regex matches, return {"original": text, "iso_date": None, "explanation": "Could not parse date format"}
   - Return {"original": text, "iso_date": iso_string, "explanation": description of conversion}

3. expand_abbreviation(token: str) -> dict (MCP-03):
   - Lowercase the token and look up in ABBREVIATIONS dict
   - If found: return {"abbreviation": token, "expansion": expansion, "confidence": "high", "source": "dictionary"}
   - If not found: return {"abbreviation": token, "expansion": None, "confidence": "low", "source": "dictionary"}

4. place_context(place: str, year: int | None = None) -> dict (MCP-04, MCP-05):
   - Step 1: Search Wikidata wbsearchentities for the place name (language=es, limit=3)
   - Step 2: If found, execute SPARQL query for place details: itemLabel, itemDescription, countryLabel (P17), coordinates (P625)
   - Step 3: Call Wikipedia REST API for summary: GET https://es.wikipedia.org/api/rest_v1/page/summary/{title} with HEADERS and timeout=10. Handle 404 gracefully (return None for summary).
   - Step 4: Return {"place": place, "year": year, "historical_name": None, "modern_name": label, "description": wikipedia_summary or wikidata_description, "wikidata_id": qid, "source_url": wikipedia_url or wikidata_url}
   - Wrap all network calls in try/except

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cleaned text to context agent | Cleaned transcription text crosses into context agent prompt -- may contain adversarial content from manuscript |
| context agent to MCP server | Agent sends entity names (from manuscript text) to MCP tools -- entity names could contain injection attempts |
| MCP server to Wikidata/Wikipedia | MCP tools make HTTP requests to external APIs with entity names from manuscript -- SSRF vector |
| Wikidata/Wikipedia to MCP server | External API responses parsed as JSON -- response injection vector |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | context agent instruction | mitigate | SEC-04 barrier in CONTEXT_INSTRUCTION: labels input text as data (OWASP LLM01:2025) |
| T-02-05 | Tampering | MCP server SSRF | mitigate | MCP tools only call hardcoded Wikidata/Wikipedia endpoints; entity names are passed as query parameters, never as URL paths for Wikidata. Wikipedia summary uses URL-encoded title but targets fixed es.wikipedia.org host only |
| T-02-06 | Tampering | Wikidata response injection | mitigate | MCP tools parse JSON responses with .get() access patterns; no eval/exec on API responses; return fixed-schema dicts regardless of API content |
| T-02-07 | Denial of Service | excessive API calls | mitigate | Context agent instruction limits to top 10 entities; all HTTP requests have timeout=10-15s; no retry loops |
| T-02-08 | Information Disclosure | User-Agent header | accept | User-Agent identifies app name only ("Palimpsest/1.0"), no PII. Required by Wikidata/Wikipedia policies |
| T-02-09 | Elevation of Privilege | MCP subprocess | accept | Server runs same Python interpreter (sys.executable) in same virtualenv; StdioServerParameters uses subprocess.Popen directly with no shell=True; no user-controlled command args |
| T-02-SC | Tampering | pip install | mitigate | No new packages installed in this plan (all deps from Plan 01). Package Legitimacy Audit in RESEARCH.md confirms all OK |
</threat_model>
